## Quick Answers

**Q: What is Zephyx?**
A: A workflow-driven cybersecurity operating platform built in Rust for authorized security assessments.

**Q: Is it free and open source?**
A: Yes, MIT / Apache 2.0 dual license.

**Q: Does it need internet or AI?**
A: No. Fully offline by default.

**Q: Which platforms are supported?**
A: Linux, Windows, macOS. See [SUPPORTED_PLATFORMS.md](../SUPPORTED_PLATFORMS.md).

**Q: How do I start?**
A: See [getting-started.md](getting-started.md) for a step-by-step walkthrough.
